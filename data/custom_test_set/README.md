# Custom Test Dataset Guidelines
Assigned to: Member A

Collect 50 to 100 real-world photos using a smartphone or webcam to evaluate the vision assistant in realistic assistive scenarios.

### Folder Breakdown:
1. `indoor/` (25–40 images):
   - Indoor corridors, doorways (opened/closed), chairs, tables, cabinets, refrigerators, obstacles.
   - Varied lighting: daytime bright, dim hallway, fluorescent lighting.
   
2. `outdoor/` (15–30 images):
   - Sidewalks, poles, benches, pedestrians, obstacles on walking paths.
   
3. `signs_text/` (15–30 images):
   - Door nameplates (e.g., "Room 204", "HOD Office"), restroom signs ("MEN", "WOMEN"), exit signs ("EXIT", "FIRE EXIT"), notice boards, product labels.
   - Clean horizontal text as well as slightly angled / blurry perspectives to test EasyOCR limits.

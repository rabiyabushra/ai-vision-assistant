# Initial Viva Notes

Q: Why YOLO?
A: It performs object detection in a single inference pipeline and is practical
for near-real-time applications.

Q: Why use a pretrained model?
A: Training a large detector from scratch requires substantial data and compute.
Transfer learning/pretrained inference is more practical for this hardware and
mini-project scope.

Q: What is OCR?
A: Optical Character Recognition converts text present in an image into machine-
readable text.

Q: Why Text-to-Speech?
A: The primary output should be auditory so that useful visual information can
be communicated without relying on a screen.

Q: Is the scene description generated by a neural captioning model?
A: In the current MVP, no. It is a transparent rule-based description derived
from object detections. A pretrained captioning model can be added later.

Q: Is the system safe enough to navigate independently?
A: No. It is an assistive prototype and detections may be incomplete or wrong.
It should not be presented as a guaranteed navigation system.
